Leave / outpass
Apply for leave or night-out, add reason and dates, optional parent/guardian approval. Owner/warden approves or rejects. Students see status and history.
Room / maintenance requests
Request room repairs (lights, plumbing, furniture). Attach photos, track status (open / in progress / resolved). Can sit alongside or inside your existing complaints flow.
Fee / dues
View fee structure, due amounts, payment history, and next due date. Link to payment (Razorpay/other) or “pay at office” instructions.
Laundry
Laundry schedule, pickup/delivery slots, per‑bag or per‑item pricing, and optional “request pickup” so students can register for a slot.
Roommate / floor directory
List of room numbers and names (and optionally contact) for same block/floor so students can find roommates or neighbors without sharing full directory.
Events / calendar
Hostel events (sports, cultural, meetings), holidays, and important dates. Students see a simple calendar or list and optional reminders.
Lost & found
Report lost/found items with category, description, photo. Others can browse and claim; warden/office can mark resolved.
Suggestions / feedback (general)
Non-mess feedback: suggestions for hostel (food, facilities, rules). Can be anonymous or named, with optional categories.
Documents
Student view of their documents (ID, agreements, receipts) uploaded by office. Download or view in app.
Gate / entry pass (QR)
Generate a time-bound QR or pass for re-entry after curfew or for guests. Guard scans to allow entry; optional log for owner.
Complaint categories
Extend complaints with categories (noise, cleanliness, safety, maintenance, other) and filters so students and owner can track by type.
Attendance / presence summary
Simple view: “Last check-in/check-out,” “Days present this month,” or a small summary so students can see their own attendance.
